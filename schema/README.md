# schema/

LinkML modules for the DataParade public ontology (structural types and slots).

Planned modules:

- `static` — System, Actor, ExternalSystem, Container, Component, Finding
- `portfolio` — Scope, in_portfolio
- `deployment` — Environment, DeploymentNode, InfrastructureNode, Instance
- `privacy` — interacts_with / uses, sends_data_to, evidenced_by

Author in LinkML. OWL may be generated later as a publishable view; do not author the schema in OWL.

See root [README](../README.md) and Jira [DATAP-641](https://dataparade.atlassian.net/browse/DATAP-641).
